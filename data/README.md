# Benchmark Dataset: LongMemEval-S

To reproduce the full 500-question empirical evaluation, place the official ICLR 2025 `longmemeval_s.json` benchmark in this directory:

```
data/longmemeval_s.json
```

### Official Download Sources:
- **HuggingFace Repository**: [xiaowang0213/LongMemEval](https://huggingface.co/datasets/xiaowang0213/LongMemEval)
- **Official GitHub**: [LongMemEval Benchmark](https://github.com/xiaowang0213/LongMemEval)

Once placed, execute the benchmark suite:
```bash
python benchmark.py
```
